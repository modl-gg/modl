## Compile-only API stub

`minecraft/platforms/vulcan-api-stub/` declares only the `me.frep.vulcan.api` types and methods that the optional Vulcan anticheat hook calls (`VulcanFlagEvent` and `Check.getName()`), so the build needs no Vulcan binary. It is written for modl and covered by modl's license. It is a `compileOnly` dependency and is never packaged: at runtime the hook binds to the Vulcan plugin the server owner installs (a soft dependency in `plugin.yml`).

## Dependencies redistributed in release artifacts

- **Server libraries.** `modl-server-<version>.jar` (`BOOT-INF/lib/`) contains the backend's runtime dependencies as unmodified jars, each with its own license metadata. The plugin jar packs none of them. `modl-embedded-<version>.zip` packs only modl's own jars (`lib/`), and its `index.txt` lists the others with their Maven coordinates and SHA-256. When it runs the built-in panel, the plugin installs that zip (downloaded, or a copy placed in `plugins/modl/server/`) and downloads the listed unmodified jars from Maven Central into `plugins/modl/server/lib/`. They include Spring Boot and Spring Framework, Apache Tomcat, SQLite JDBC (with the SQLite native library), jOOQ (open source edition), Flyway, HikariCP, the MariaDB, PostgreSQL and MySQL JDBC drivers, Jackson, Google protobuf, protovalidate-java, the AWS SDK, Yubico WebAuthn, Bouncy Castle (`bcprov-jdk18on`, MIT-style Bouncy Castle licence, text in [`licenses/bouncycastle-MIT.txt`](licenses/bouncycastle-MIT.txt); used for Argon2id password hashing), Apache HttpClient, Logback and SLF4J, among others. Their licenses include Apache-2.0, MIT, BSD-2-Clause (PostgreSQL JDBC), BSD-3-Clause, EPL-2.0, LGPL-2.1 (MariaDB Connector/J) and EPL-1.0 or LGPL-2.1 (Logback, offered under either). MySQL Connector/J is GPL-2.0 with the Universal FOSS Exception 1.0, which permits distributing it unmodified alongside modl's AGPL-3.0 code; its license text and the exception ship inside its own jar.
- **Panel assets.** The panel served by the server is a Vite bundle of the npm packages declared in `panel/` (React, Radix UI, TanStack Query, three.js, i18next and others; versions and licenses in `package-lock.json`). It includes the Audiowide font (`@fontsource/audiowide`, latin subset), Copyright (c) 2012 Brian J. Bonislawsky DBA Astigmatic, Reserved Font Name "Audiowide", SIL Open Font License 1.1, text in [`licenses/audiowide-OFL-1.1.txt`](licenses/audiowide-OFL-1.1.txt). The fonts that the public site theme can use are bundled the same way (`@fontsource-variable/*`, weight axis), each under the SIL Open Font License 1.1: Inter, Copyright 2016 The Inter Project Authors, text in [`licenses/inter-OFL-1.1.txt`](licenses/inter-OFL-1.1.txt); Lora, Copyright 2011 The Lora Project Authors, Reserved Font Name "Lora", text in [`licenses/lora-OFL-1.1.txt`](licenses/lora-OFL-1.1.txt); Nunito, Copyright 2014 The Nunito Project Authors, text in [`licenses/nunito-OFL-1.1.txt`](licenses/nunito-OFL-1.1.txt); Space Grotesk, Copyright 2020 The Space Grotesk Project Authors, text in [`licenses/space-grotesk-OFL-1.1.txt`](licenses/space-grotesk-OFL-1.1.txt). ## Runtime dependencies not shipped by modl

PacketEvents ([retrooper/packetevents](https://github.com/retrooper/packetevents), GPL-3.0) is installed by the server owner. Libraries the plugin downloads from Maven Central at runtime through Libby (protobuf-java, Gson, SnakeYAML, Java-WebSocket, Lamp and SLF4J) are fetched on the server, verified against pinned checksums and, for protobuf-java and Gson, relocated there; they are not part of the plugin jar. When an import from another plugin needs one, the plugin downloads its database driver the same way, unmodified and loaded in its own class loader: HSQLDB (BSD-3-Clause style HSQLDB license), H2 1.4.200 (MPL-2.0 or EPL-1.0), SQLite JDBC (Apache-2.0), MariaDB Connector/J (LGPL-2.1) or PostgreSQL JDBC (BSD-2-Clause).
